# Bank Customer Churn Analysis (Multi-Tool Challenge)

This repository is a personal challenge to analyze the exact same dataset of 10,000 bank customers using three different tools: Excel, Python, and Power BI. The goal is to see how the analysis and workflows differ across each tool.

---

## 📁 Repository Structure

Click on the folders below to see the specific code, dashboard, and insights for each tool:

* 📁 [Analysis With Excel](./Analysis%20With%20Excel/) — Contains the initial KPI dashboard and basic customer data exploration.
* 📁 [Analysis With Python](./Analysis%20With%20Python/) — Contains the Jupyter Notebook for data cleaning, segmenting zero-balances, and high-res distribution plots.
* 📁 [Analysis With Power BI](./Analysis%20With%20Power%20BI/) — Contains the interactive report, custom grid layout, and the 7 analytical charts.
---

##  Key Business Insights Discovered

* **The Complaint Factor:** Customers who filed a complaint showed a massive 99.5% correlation with leaving the bank.
* **Geographical Risk:** Germany showed a much higher churn rate (32.4%) compared to France and Spain, despite having fewer overall customers.
* **Age Demographics:** Churn peaks heavily among customers aged 51 to 60, reaching a 56.21% drop-off rate.
